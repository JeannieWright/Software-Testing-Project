
## 👋 Welcome to Jeannie's Software Quality Engineering & Verification Project

This project demonstrates an evidence-driven approach to software quality engineering using a live web application as the system under test.

The project goes beyond traditional functional testing by applying structured verification, risk-based testing, test automation, accessibility evaluation, API testing, performance analysis, security-focused testing, defect management, and continuous integration practices.

The objective is to build a repeatable quality and verification process that traces application requirements and identified risks to test coverage, execution results, defects, supporting evidence, and release-quality decisions.

The project demonstrates quality-engineering practices applicable to enterprise, secure, regulated, and mission-critical software environments.

## Core Quality Areas

- Requirements analysis and traceability
- Risk-based testing
- Manual and exploratory testing
- Automated UI testing
- API and backend validation
- Accessibility and WCAG/Section 508-oriented testing
- Security-focused application testing
- Performance and reliability testing
- Defect investigation and root-cause documentation
- CI/CD quality gates
- Test evidence and reporting
- Release-readiness evaluation

Rather than treating testing as a one-time activity, this project aims to build a reusable, evidence-driven quality engineering and verification system. Automated test suites, supporting scripts, test reports, and CI workflows will provide repeatable evidence of application quality, support requirements verification, and help detect future regressions.

The project will document:

- Requirements, testing, and design decisions
- Risk identification and test prioritization
- Tool installation and configuration
- Manual and automated test execution
- Requirements-to-test traceability
- Defects, risks, security considerations, accessibility issues, and usability concerns
- Supporting evidence and test results
- Recommended solutions and preventive safeguards
- Technical obstacles and troubleshooting
- Successful and unsuccessful approaches
- Accomplishments and measurable outcomes
- Release-readiness considerations
- Lessons learned and future improvements

The completed repository will serve as both a record of the application's quality assessment and a professional portfolio demonstrating practical quality engineering and verification skills across software testing, test automation, API testing, scripting, framework development, accessibility testing, security-focused testing, performance analysis, defect management, evidence-based reporting, and CI/CD.

As the project evolves, we will incorporate additional verification practices to demonstrate approaches applicable to enterprise, secure, regulated, and mission-critical software environments.
